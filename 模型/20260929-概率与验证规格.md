## 2. 证据不足期的概率列输出（C19）

三情景表概率列在证据不足期显示三位置坐标＋参照百分位，接受概率固定"暂不可估"（C6）：

1. **p/L 参照百分位**：报价 p ÷ 当前挂牌 L，在近两年 R 分布中所处百分位。R 分布层级与检验线一致（小区近两年成交 ≥10 笔用小区分布，否则全市）。展示层四舍五入到百分点整数。
2. **p/M 相对估值位置**：p ÷ M，并标注与 90% 名义区间上下沿的关系（区间内／下沿下／上沿上）。
3. **与检验线 V 的距离**：p − V（及占比），附解锁挂牌价 L\*（规格 1.0 §2.6）。

标注文本模板（每次输出必带）：

> 该层级近两年成交中，约 X% 的成交价／最终挂牌比值不高于此报价位置。这是**成交样本的价格参照，不是接受概率**——未成交、撤牌、拒绝报价的样本不可见（C6，幸存者口径）。

备选（未采纳）：纯定性三档（低于检验线／检验线—中位／中位以上），不显示百分位数字。

## 3. 真实报价事件记录规范（C20）

**触发**：t0＝报价及关键条件确认传达卖家时点；仅发中介未确认转达＝传达状态未知，不触发。

**登记字段**：

| 字段 | 说明 |
| --- | --- |
| 报价编号 | 每次价格或关键条件变化新编号（§2.2）；原编号记结束原因 |
| t0／金额 p／条件 c | 条件含付款、交房、税费、附带条件、有效期 |
| 传达方式与确认状态 | 何人转达、何时确认 |
| 7／14／30 天节点 | 回应、还价、条件变化、报价是否仍有效 |
| 结束标签／结束日期 | 见下表 |
| 分组键 | 房源号（同一卖家多轮关联） |

**结束标签枚举与统计处理**：

| 标签 | 统计处理 |
| --- | --- |
| 接受（含条件性——共有人未一致） | 正结局；条件性接受单独标注 |
| 明确拒绝 | 进入"未接受"分母 |
| 还价 | **独立标签**：原报价结束；还价金额与原报价关系逐条记；不并入拒绝 |
| 我方撤回／到期失效／被新报价替代／卖家撤牌／失去联系 | 右删失——不入"未接受"分母 |
| 卖给他人 | 竞争性失败，单独标注（可作竞争通道输入） |
| 观察未满 | 右删失，30 天期满后转正 |

记录落位：02 套内《卖家行为与出价分析.md》每轮节＋谈判记录 R 序列联动；假设演练（未实际发出的报价）单独分区，永不与真实事件混同（§7.2 既有约束）。

## 4. 验证门（C21；预注册——看结果之前约定，此后仅在未看结果时可修订）

- **数量门**：≥6 个完整 30 天观察的真实报价事件，其中接受 ≥2、未接受 ≥2。
- **校准门**：时间外（后段事件检验前段拟合）Brier 分数不劣于恒定基线；报价高低与估测接受概率单调一致（更高报价不被判更难接受，§7.2 原则）。
- **输出纪律**：过门后的数值必须同屏显示样本量、不确定性区间、适用报价范围、模型版本；未过门一律"暂不可估"。
- 修订登记：门与标准的任何修订在搭建方案更新记录留痕，并注明修订时点是否已接触测试结果。

## 5. 回放执行规格（C22；C10 A 档操作化）

- **执行位置**：WP4，106 只读执行；报告归 change evidence（审2 证据）。
- **输入冻结**：19 小区清单（06 manifest）、窗口 2024-08-31 至 2026-08-31、staged run_20260831T041648Z、代理＝成交日前 365 天同小区可比中位（≥3 笔才计，不足记缺失）。
- **输出报告**：逐笔 T（＝代理×(1+δ)，δ 分别取 0／−1%／−2%／−3% 四档）vs 实际成交价的有符号偏差、绝对偏差；覆盖率与缺失原因；两基线对照（无修正代理、挂牌×近期 R 分位）；按成交年分层（R 漂移披露）。
- **结论许可（仅两条）**：①检验 T 规则的系统性偏差（如各 δ 档位下偏差的偏移方向）；②为 δ 档位校准提供线索——**修改档位走 V1.5+ 流程，不自动改**。
- **禁止**：据此宣称谈判成功率、节省金额或规则"有效"（C6／C10 既有约束）。

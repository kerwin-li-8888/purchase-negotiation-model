# 出价计算与接口规格（静态层 V1 · 出价模块）

> 创建日期：2026-09-29｜版本：1.0｜状态：已定稿（2026-09-29 用户复核无意见，阶段三正文层关闭）
> 上位文件：[卖家行为与预估购买价模型搭建方案](./20260929-卖家行为与预估购买价模型搭建方案.md)（§6 约束＋表决 C15—C18）、[卖家行为规则表](./20260929-卖家行为规则表.md)（让步档位输入，1.0）
> 定位：定义静态层 V1 的三价计算口径、参数表、接口契约、匿名算例与边界案例。全部幅度参数为**初始规则假设，尚未证明经验有效**（C10 回放与前瞻验证后校准）。
> 公开性：按 07 可公开标准写。算例数字为虚构；参数表为市场聚合统计（无房源身份）。

## 1. 输入与输出

| 输入 | 来源 | 口径 | 缺失处理 |
| --- | --- | --- | --- |
| 市场估值 M | 105 CAND V2 候选 rc-vN（只读引用；2026-10-01 起 103 桥切 V2 候选入口，原 CAND M1 通道退役） | 带候选版本、日期、90% 区间、状态与降级说明；**候选态、非正式报价**（开发侧证据、未过独立重验），超龄拒绝（RC_MARKET_DATA_STALE）＝待取数刷新、非故障 | 无估值不计算，显示"待估值" |
| 当前挂牌 L | 02 动态跟踪最新行 | 最新有来源日期的挂牌价 | 无挂牌不计算（无议价对象） |
| 让步档位 | 规则表 4.3 槽位产出 | 档 0—3，判据见 §2.2 | 无 G1 让步记录＝档 0 |
| 买方侧条目 | 01 边界引用 | 每项：类型、理由、有效期 | 无＝δ+ 为 0 |
| 预算承受上限 | 01 | 用户确认金额与日期 | 缺失则上限不可执行（见 §5 案例 3） |
| R25 参数 | 本规格 §2.6 参数表 | 近两年窗口，随 staged 快照滚动 | staged 未更新沿用上次并标日期 |

输出（每次计算按日期追加，不覆盖历史）：

1. 修正账本：卖方侧档位（判据＋证据编号）＋买方侧逐项（类型/理由/有效期/01 引用）＋δ总。
2. 三价：开价 O、目标价 T、上限 U（各带依据与快照日期）。
3. 三情景比较表（§9 章法）：较低＝O、中间＝T、较高＝U，每行带条件、支持证据、障碍与反证、概率状态（阶段四前一律"暂不可估"，C6）、下一步。
4. 检验线 V 与解锁挂牌价 L\*（§2.6）。
5. 未计入项披露：未参与合成的判断及其可能改变结论的方向（§6.5 既有约束）。

## 2. 计算口径

### 2.1 总公式

`T = M × (1 + δ总)`，`δ总 = δ−(档位) + δ+(合计)`，`δ总 ∈ [−10%, +10%]`。
V1 实际可达 `δ总 ∈ [−3%, +3%]`——±10% 是护栏不是目标，用满需验证支持。

### 2.2 卖方侧 δ−：让步档位表（C15）

| 档 | 判据（须同时满足） | δ− |
| --- | --- | --- |
| 0 | 无有日期的让步记录 | 0 |
| 1 | ≥1 次有日期下调，且最近一次 ≤6 个月 | −1% |
| 2 | ≥2 次有日期下调，且累计降幅 ≥5% | −2% |
| 3 | ≥3 次有日期下调，且累计降幅 ≥9%，且最近一次 ≤3 个月 | −3% |

- 证据一律 G1（App 调价时间轴／挂牌价变动行）；G2 转述"愿意降"不入档位，只作提问。
- 累计降幅 =（初始挂牌 − 当前挂牌）／初始挂牌，口径取 App 时间轴；撤牌重挂则历史清零、按新挂牌口径重算。
- 档位互斥取最深档；卖方侧只有这一项，不存在卖方侧加总（C16 天然去重）。

### 2.3 买方侧 δ+（C13／C16）

| 条目 | 幅度 | 准入 |
| --- | --- | --- |
| 我方时间成本上升 | +1% | 具体事件（如租约 ≤6 个月到期且续租成本高），01 引用 |
| 替代选项质量恶化 | +1% | 06 池内同档候选经核实明显减少，01 引用 |
| 房源独特性 | +2% | 逐条列出不可替代的匹配点；列不出就不计 |

合计 ≤+3%；每项带理由与有效期，到期自动退出并重算。卖家侧与市场侧信号永不进 δ+。

### 2.4 上限 U 与开价 O

- `U = min(M 的 90% 名义区间上沿, 01 预算承受上限)`；预算未确认则 U 标"不可执行"。
- `O = T × (1 − 预留)`；预留随让步档位**反向**（C17）：档 2—3 → 3%（快收口）、档 1 → 5%、档 0 → 7%（试探性开价＋明确有效期）。

### 2.5 取整与比较

全链用精确值计算与比较（穿线、上限冲突、交集判断）；仅展示层四舍五入到整万元。

### 2.6 检验线 V 与解锁挂牌价（C17）

- `V = L × R25`；R25 取近两年窗口成交／最终挂牌比率分布的 25 分位。
- 层级回落：小区近两年成交 ≥10 笔 → 小区 R25；否则全市 R25。
- 穿线处理：`O < V` → 开价标"低于检验线"，转等待／换目标建议，**不自动上调**；`T < V` → 目标同样标注（当前出价空间未开）。
- 解锁挂牌价：`L* = T / R25`——挂牌需降到 L\* 以下，目标价 T 才不穿线。检验线随卖家降价自动下移。
- R25 参数表（窗口 2024-08-31 至 2026-08-31，staged 口径日 2026-08-31，全量 sale_record 匹配）：

| 层级 | R25 | 样本 |
| --- | --- | --- |
| 全市（兜底） | 0.856 | n=80,880；四分位 0.856／0.897／0.930 |
| 小区C09 | 0.895 | n=55 |
| 小区C10 | 0.863 | n=51 |
| 小区C03 | 0.857 | n=35 |
| 小区C07 | 0.852 | n=34 |
| 小区C15 | 0.875 | n=30 |
| 小区C04 | 0.821 | n=17 |
| 小区C18 | 0.871 | n=16 |
| 小区C17 | 0.886 | n=15 |
| 小区C01 | 0.892 | n=12 |
| 其余 10 小区 | 用全市 0.856 | 近两年成交 <10 笔 |

滚动纪律：staged 新 run 时重算本表并登记变更；小区集合或窗口变化触发阈值复核义务（沿用 06 成交色标同款纪律）。

### 2.7 无可行交集

`T > U` 时列冲突，比较三选项：等降价、降低目标（收窄 δ）、换目标；不抬上限、不把截断价伪装成合规目标价（§6.7 既有约束）。

## 3. 接口契约

- **触发**：输入变化才重算——新调价／新沟通／买方侧条目增减或到期／预算更新／staged 滚动。无变化不重算，不因时间流逝单独重算。
- **留痕**：每次输出带规则版本（本文件版本号）、输入快照日期（M 版本、L 行日期、档位判据日期、01 确认日期、R25 口径日）。
- **02 落位**（C18）：套内《卖家行为与出价分析.md》，每轮一节（日期＋规则版本＋输入快照＋判断表摘要＋修正账本＋三价＋三情景表＋提问清单＋未计入项），按日期追加、旧轮不覆盖，编号与逐轮策略 R 序列对齐。空白模板随实施 change 落地（WP3）。
- **非价格条件**：静态层一律不折价，以并列条件进三情景表与概率输入；价格当量折算归动态层（设计确认归位不变）。

## 4. 匿名完整算例（虚构数字）

输入：M=230 万（90% 区间 186—288 万，正常状态）；L=285 万；App 时间轴初始 315 万、4 次有日期调价、最近一次 20 天前（累计降幅 9.5%）；买方侧：租约 5 个月内到期 → 时间成本 +1%，其余不计；预算上限 250 万（01 已确认）；小区近两年成交 17 笔 → 小区 R25=0.83（虚构）。

1. 让步档位：4 次 ≥3、9.5% ≥9%、20 天 ≤3 月 → **档 3**。
2. δ总 = −3% + 1% = **−2%**（带内）。
3. T = 230 × 0.98 = 225.4 → 展示 **225 万**。
4. U = min(288, 250) = **250 万**。
5. 预留（档 3）= 3% → O = 225.4 × 0.97 = 218.6 → 展示 **219 万**。
6. V = 285 × 0.83 = 236.6；L\* = 225.4 ÷ 0.83 ≈ 271.6 万。
7. 判定：O（218.6）< V 且 T（225.4）< V → **开价与目标均低于检验线**：当前出价空间未开；挂牌降至约 271 万以下时 T 进入可出区间。输出建议＝等待卖家进一步调价（线随 L 下移）或换目标，不自动上调出价。
8. 三情景表：较低＝219 万（试探，穿线标注）／中间＝225 万（目标，穿线标注，附 L\*≈272 万）／较高＝250 万（预算内、线以上，标注"仅买方侧 δ+ 激活或竞争概率恶化时考虑"，当前 δ+ 仅 +1% 未达）。
9. 未计入项：出售压力仅陈述（期限未知）、沟通零记录、盈亏深盈利（方向性假设不进 δ）。

## 5. 边界案例

| # | 情形 | 处理 |
| --- | --- | --- |
| 1 | 无 G1 让步记录 | 档 0，δ−=0，预留 7%，开价附明确有效期（试探性信息动作）；检验线保护同样适用 |
| 2 | 撤牌重挂 | 让步历史清零、按新挂牌重算档位；旧轮次留痕不删 |
| 3 | 预算未确认 | U 不可执行：展示 90% 上沿但标"未经预算校验"；不输出可执行三价，只出 T 与分析 |
| 4 | T > U（无可行交集） | 列冲突与三选项（等降价／收窄 δ／换目标），不抬上限 |
| 5 | 估值降级或状态异常 | 沿用 105 降级说明，输出标"估值受限"，不静默继续 |
| 6 | G2 转述让步未落实 | 不入档位（仅提问项），档位维持原判 |
| 7 | 买方侧条目到期 | 自动退出 δ+ 并重算，账本留痕 |
| 8 | 小区近两年成交 <10 笔 | R25 用全市 0.856，输出标注回落层级 |
| 9 | 新调价与新竞争同日出现 | 分别入槽：调价进档位（δ−），竞争进概率通道与情景标注，互不混同（C13） |

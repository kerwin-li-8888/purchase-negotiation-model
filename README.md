# 购房谈判策略模型

二手房购房谈判的两层开源体系：**一套可手工执行的谈判方法**（方法层）＋ **一个预估购买价模型**（模型层，静态层 V1）。

核心思路：买方看不到卖家的底价，但卖家的行为会留下证据——挂牌时长、调价轨迹、同类成交／挂牌比率（经验议价率）、入手价盈亏心理。本库把这些证据整理成可核实的记录规则（方法层），再形式化为可复算的出价规则（模型层），输出：

- **三价**：开价 O／目标价 T／上限 U；
- **可成交性检验线 V 与解锁挂牌价 L\***：出价低于检验线提示成交概率低，转向等待或换目标而非追价；
- **三情景比较**（较低＝开价／中间＝目标／较高＝上限），概率列在验证门通过前一律「暂不可估」。

模型边界（设计立场）：估值锚＝市场价权威，只读引用不修正；行为信号只修正出价策略；分析与执行分离，报价与对外承诺始终由人决定。

## 两层怎么配合

1. **方法层收集证据与边界**：用[房源信息与沟通](./模板/模板-房源信息与沟通.md)模板登记每条消息（E 编号、来源链、状态五态），用[我方边界](./模板/模板-我方边界.md)模板逐步确认时间、替代选择与承受上限；
2. **模型层算三价**：按[使用说明](./使用说明.md)的八步流程——填七槽位判断表（[规则表](./模型/20260929-卖家行为规则表.md)）→ 判让步档位 → 合成 δ → 算三价＋检验线（[出价规格](./模型/20260929-出价计算与接口规格.md)）；
3. **回到方法层执行与记录**：按[逐轮策略](./模板/模板-逐轮策略.md)模板记录判断、行动与回应分支，真实报价事件按[概率规格](./模型/20260929-概率与验证规格.md)十标签登记。

## 快速开始

1. 读[使用说明](./使用说明.md)。
2. 只想手工谈判：从三份模板开始，按「每轮怎样做」五步走，不填模型也能用。
3. 要跑模型：按使用说明「模型层怎么用」的阅读顺序与八步流程执行一轮分析。

## 数据依赖与脚本说明

`模型/scripts/` 下两个脚本在源系统中只读消费本地 staged 外部成交明细（约 24.5 万条，仓库**不含**底层数据，运行时需用 `--manifest`／`--src` 显式指定数据位置）：

- `r25_table.py`：生成 R25（经验议价率 25 分位）参数快照——全市与小区两层，小区近两年成交 ≥10 笔出小区值，否则回落全市；
- `replay_price_reference.py`：一次性回放校验（WP4／C10 A 档时点对齐价格参照检查），输出落 `模型/exports/replay_wp4/`。

`模型/exports/r25/` 为既有快照（口径日 2026-08-31、窗口两年、全市 n=80,968、R25=0.8558），可作为示例参数直接查表使用；换数据源需按[出价规格](./模型/20260929-出价计算与接口规格.md) §2.6 同一口径重算。

## 公开性与隐私

本库按可公开标准维护：不含具体房源身份、报价与个人边界数值；`exports/` 仅含市场聚合统计，其中小区一律以假名（小区C01–C19）出现，真实小区名单不随库发布。模板填写内容（我方边界、逐轮过程、沟通记录）属私密信息，由使用者自行保管、不入库。

历史文档中出现的「105／106／01／02／06」等代号指提取本库的源系统板块：105＝估值引擎（市场价权威）、106＝购房决策系统、01＝家庭资产与建议、02＝房源档案、06＝一页式房源分析。其中私密板块（01／02 等）的内容未随库开源，相关链接已改为文字说明。

## 来源与状态

本库提取自一套个人购房决策系统的两个谈判相关板块（方法板块＋模型板块），于 2026-10-10 合并为单一体系。文档状态：方法层 V0.2、模型层静态层 V1（三份规格 1.0 定稿）；动态层（逐轮让步策略、效用函数形式化）与成交概率量化为规划中的后续层。外部对标与理论出处见[外部调研](./外部调研/)。

## 一、结论先行

**通用谈判模型有真货可吸收，但吸收方式是「概念与口径」，不是代码。** ANAC/GENIUS 自 2010 年起十余年竞赛沉淀出的三大件——①议题×权重×保留值的效用函数、②随时间衰减的让步轨迹（aspiration 曲线）、③基于对手出价历史的对手建模——恰好补上「预估购买价＝估值锚＋行为信号修正」缺的形式化骨架。但它们假设双方效用可精确计算、出价可自动生成，与本体系「可解释、轻量、人工拍板」的立场冲突，因此**只取其表示层（怎么形式化），不取其执行层（自动 agent）**。

分 RQ 一句话结论：

- **RQ1 效用函数：可形式化。** NegMAS 的线性可加效用函数（议题×值函数×权重＋保留值）与 01「我方边界」填写件一一对应，预算上限、时间压力、替代选择、条件交换项都有现成槽位。
- **RQ2 对手建模：可吸收概念。** ANAC 获奖-agent 主流做法是频次统计对手历史出价（估计对方偏好）；近期框架加入实时行为分类＋会话内策略切换。映射到本体系＝让步曲线分类＋急售/坚守/观望三类型切换表，用可解释规则实现，不上深度学习。
- **RQ3 出价策略：可吸收口径。** Boulware（前硬后软）/Linear/Conceder 让步曲线族给「开价/目标/上限三价随轮次怎么动」提供了参数化表达；本地经验议价率（中位约 95%）作为先验注入目标价定位。
- **RQ4 评估与回放：可吸收口径。** AgenticPay 的评分配方（成交奖励＋公平质量＋时间折扣）可直接改造成用本地成交明细做「影子回放」的评分标准。
- **RQ5 吸收判定：** 概念/口径大量吸收，代码与平台一律不引入（判定表见第三节）。另有两个对方案清单的**更正**：arXiv:2505.22998 已被撤稿；方案给定的 GENIUS 仓库地址不存在（正本线索见 2.3）。

一条对策略层的警示性发现：AgenticPay 用 5 个 LLM 实测 111 个谈判任务，**所有模型当卖家都比当买家得分高**（买卖角色系统性不对称，GPT-5.2 卖 81.1 vs 买 58.5），且 43%–46% 的谈判失败发生在价差已极小的「最后一公里」。这佐证本体系的既有立场：AI 做信息整理与沙盘推演，出价权保留在人。

## 二、分对象发现

### 2.1 NegMAS（精读，RQ1/RQ3 主力）

| 项 | 内容 |
| --- | --- |
| 是什么 | Python 自动谈判 agent 库：双边/多边谈判、多协议、多智能体仿真；NEC-AIST 联合实验室开发 |
| 状态 | 活跃维护（README 2026-02 仍有更新，3,572 commits），BSD-3-Clause |
| 入口 | [github.com/yasserfarouk/negmas](https://github.com/yasserfarouk/negmas) ｜ [negmas.readthedocs.io](https://negmas.readthedocs.io/) |

关键发现（含原文引用）：

1. **效用函数表示**：`preferences` 模块，核心类 `LinearAdditiveUtilityFunction`＝各议题值函数×权重＋`reserved_value`。文档教程原文：

   ```python
   seller_utility = LUFun(
       values={"price": IdentityFun(), "quantity": LinearFun(0.2),
               "delivery_time": AffineFun(-1, bias=9)},
       weights={"price": 1.0, "quantity": 1.0, "delivery_time": 10.0},
       outcome_space=session.outcome_space,
       reserved_value=15,
   ).scale_max(1.0)
   ```

   价格、数量、交期三议题权重可差一个量级，保留值独立设定——**这就是「我方边界」的形式化槽位**。
2. **让步轨迹**：`TimeBasedConcedingNegotiator` / `AspirationNegotiator` / `BoulwareTBNegotiator`。aspiration 用 `PolyAspiration(1.0, "boulware")`（从 1.0 起、慢让步），出价时按 `a = (max − min) × asp.utility_at(relative_time) + min` 把「此刻期望效用」映射回具体出价。
3. **默认接受策略**（文档原口径）：「接受当且仅当该出价对我方的效用 ≥ 我方此刻将提出的方案的效用」——一个干净、可解释的收口判据。
4. **反应式与组件**：`TitForTatNegotiator`；Genius 风格 BOA 组件可拼装（如 `GTimeDependentOffering(e=0.2)` 时间型出价＋`GACTime(t=0.95)` 时间型接受）；频次型对手模型组件 `GSmithFrequencyModel`。
5. **生态**：`negmas-llm`（LLM 谈判 agent）、[negmas-genius-agents](https://github.com/autoneg/negmas-genius-agents)（GENIUS/ANAC agent 的重实现与 wrapper，AGPL-3.0/GPL-3.0）、[negmas-geniusweb-bridge](https://github.com/autoneg/negmas-geniusweb-bridge)。

对本体系的含义：「我方边界」模板可直接映射——预算上限→价格议题值域端点；时间压力→时间衰减；替代选择（可买别套/继续租住）→保留值＝不成交效用；条件交换项（首付比例、交房时间、税费承担）→低权重议题。三价定位与轮次动态可用 aspiration 口径参数化。

### 2.2 AgenticPay（精读，RQ4 主力）

| 项 | 内容 |
| --- | --- |
| 是什么 | 买卖场景 LLM/VLM 多智能体谈判的 benchmark＋仿真框架；UC Berkeley Dawn Song 组（Liu, Gu & Song） |
| 状态 | 论文 2026-02-05 提交；仓库 README 自述为 NeurIPS 2026 投稿（**录用状态待核实**）；MIT License |
| 入口 | 论文 [arXiv:2602.06008](https://arxiv.org/abs/2602.06008) ｜ [github.com/SafeRL-Lab/AgenticPay](https://github.com/SafeRL-Lab/AgenticPay) |

关键发现（含原文数字）：

1. **规模口径有版本差异，引用时需注明**：论文口径 **111 个任务**（31 基础＋80 现实＝10 场景×8 市场拓扑），方案所述「110+」即此；仓库现行 README 口径 **160 任务**（4 场景×8 拓扑×5 任务＋25 个共享多模态场景）。场景含日常（二手手机/二手车/**度假短租**）、专业服务（网站开发/商业摄影/家装）、采购（SaaS/原材料）、金融资产（名表/企业收购）；README 多模态场景清单含「公寓租赁」（s21–s25）。**最接近居住类资产的是度假短租/公寓租赁，无房产买卖专项场景。**
2. **评分配方**（论文 Algorithm 1，原文数字）：议价区 Z＝p^max−p^min；买方效用 r_b＝(p^max−p)/Z、卖方效用 r_s＝(p−p^min)/Z；质量 Q＝4·r_b·r_s（均分时最大）；效率折扣 d＝γ^(t−1)，γ＝0.99；**GlobalScore＝d·(D＋Q·W＋E)**，其中成交奖励 D＝30、质量 W＝55、效率 E＝15，失败罚 F＝15。
3. **实测发现**（GPT-5.2、Claude Opus 4.5、Gemini 3 Flash、Qwen3-14B、Llama-3.1-8B，温度 0）：闭源三强 GlobalScore 81.7–86.9、成交率 100%；开源两模型 32.5–63.9、超时率 20.7%–48.6%。**买卖角色不对称**：所有模型当卖家得分更高（GPT-5.2：卖 81.1 vs 买 58.5），跨对弈显示系统性买方劣势（Claude 差 26.0 分、Qwen 差 43.2 分），作者猜测训练语料中「说服性卖」多于「策略性买」。**最后一公里失败**：43.5%（Qwen）与 46.3%（Llama）的失败发生在价差已 ≤5 单位时——找得到议价区，收不了口。金融资产最难（Gemini 从 88.3 掉到 68.1）。
4. **Agent 设计口径**：买卖双方各持**私有保留价**（买方最高愿付 p^max／卖方最低要价 p^min），注入系统提示并明示保密；记忆模块存 (role, content, round) 元组；结构化动作解析；最多 20 轮；README 另提到提示词层对手建模。成交仅在议价区内有效。

对本体系的含义：评分公式三件套（成交/质量/效率折扣）就是「影子回放」的现成评分口径（见第五节第 4 条）；「最后一公里」发现提示逐轮模板应把收口规则显性化；买方系统性劣势佐证「出价权在人」。

## 四、与《20260926-二手房谈判外部调研-快扫版》的衔接

- 0926 快扫管「机理与市场」：卖家为什么硬（损失厌恶/参考点依赖）、议价空间量级（北京 7.3%／11 城 17.7%／广州 <15%，口径不可直接套用）、实务九条共识。本报告不重复其内容。
- 本报告补「形式化层」：把 0926 已确认的机理与自有行为信号装进通用谈判模型的表示层（效用函数、让步曲线、对手分类）。
- 0926 两条待吸收线索在本报告落地：① **卖家锚点＝买入价**（损失厌恶）→ 并入对手心理状态先验：入手价盈利→让步空间大（Conceder 型概率高）、亏损→前硬后软（Boulware 型概率高）；② **贝壳「诚意卖」新模式** → 策略轨道切换的特例（心理底价＋两次出价机制下，逐轮拉锯策略不适用）。
- 0926 的外部议价基准与本报告的先验注入同口径衔接：外部量级只作背景，先验一律用本地成交明细自算（19 个目标小区中位约 95.4%、四分位约 91%–98%，小区优先、不足回落板块/全市）。

## 五、预估购买价规则表增量建议

对照方案第五节备忘（估值锚不动、策略层修正），建议规则表按以下五条增量搭建：

1. **效用函数骨架**（RQ1）：出价方案效用＝Σ w_i·v_i(x_i)，议题集建议起步为 价格/付款方式/交房时间/税费承担/腾房安排；权重人工设定；保留值＝不成交效用（替代方案比较的产出，即 01 边界件）。价格议题的值域端点＝家庭预算上限（硬约束，与谈判上限分开记）。
2. **经验议价率先验**（RQ3）：目标价初值＝挂牌价×先验分位（默认取小区议价率中位约 95.4%，进攻/保守分位取四分位 91%–98%）；分布随成交明细滚动更新。估值锚（M1＋90% 区间）只读不动。
3. **对手三分类与切换表**（RQ2）：信号→类型→策略切换，全部可解释规则。示例骨架：调价频次高/近期新调→急售倾向（Conceder 型）→我方快收口；长期不调＋亏损入手→坚守（Boulware 型）→维持报价、用新独立成交证据更新其锚点、转非价格议题；带看冷清＋长期挂牌→观望→时间压力测试＋提高我方替代方案权重。心理状态先验（赚/亏）由入手价模块（上次交易时间→入手金额估计）给出。
4. **影子回放评分口径**（RQ4）：以历史挂牌轨迹为初始态，按规则表生成出价序列，对照实际成交价评分：S＝d·(成交奖励＋质量项＋效率项)，质量项可用「成交价相对先验中位的改善」（即归一化效用 r），d＝按轮次的时间折扣。本地 245,410 条成交明细可标注；先跑小区级批量回放校准参数，再用于个案。
5. **纪律边界**（RQ5）：全部实现为可解释规则/查表＋人工判断辅助表；不引入 NegMAS/GENIUS 等平台依赖；不搞全自动出价（AgenticPay 买方劣势＋LLM 偏离理性双重实证）；贝壳「诚意卖」等机制化新房源先识别机制、再切策略轨道。
